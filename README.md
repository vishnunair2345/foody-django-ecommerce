# 🥕 Foody - Vegetable Store E-Commerce

Foody is a Django-based vegetable store e-commerce web application developed using Python, Django, MySQL, HTML, CSS, JavaScript, and SCSS.

## 🚀 Features

- User registration and login
- Vegetable/product listing
- Product details
- Shopping cart
- Order management
- Payment workflow
- Order history
- Delivery management
- Admin dashboard
- MySQL database integration
- Responsive user interface

## 🛠️ Technologies Used

- Python
- Django
- MySQL
- HTML5
- CSS3
- JavaScript
- SCSS
- Bootstrap
